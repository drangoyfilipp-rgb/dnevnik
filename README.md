# Дневник

Личное Android-приложение для дневника «Госуслуги Моя школа» (www.gosuslugi.ru/school): расписание, задания с файлами, оценки, итоговые. Работает без интернета на сохранённых данных.

- Вход через Госуслуги на официальной странице gosuslugi.ru/school/feed (WebView). Пароль не сохраняется.
- Данные: API `www.gosuslugi.ru/api/myschool/v1/datamart` — запросы веб-версии перехватываются в WebView и повторяются приложением; запасной путь — данные, которые загружает сама веб-версия.
- Код на вход (включён по умолчанию) + отпечаток.
- Без рекламы и аналитики, офлайн-кэш на телефоне.
- «Ещё → Диагностика»: последняя ошибка и экспорт путей API и структуры JSON без значений.

Скачать: [последняя сборка](https://github.com/drangoyfilipp-rgb/dnevnik/releases/latest) — `dnevnik-arm64.apk`.

Сборка: GitHub Actions (`.github/workflows/android.yml`), versionCode = номер запуска, тег `build-N`.
Подпись: `android/app/release.p12.enc` (зашифрован), расшифровывается в CI секретом `KEYSTORE_PASS`.
