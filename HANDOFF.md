# Дневник — передача проекта следующему ИИ

Личное Android-приложение (Flutter) — школьный дневник для одного ученика (11 «А», ЛНР). Читает данные из «Госуслуги Моя школа». Последний релиз: **build-4** (main `afce5da`), владелец проверил установку 2026-11-17.

## Как собирается
- Сборку делает только CI: `.github/workflows/android.yml` (Flutter 3.38.5, `flutter analyze` + `flutter test`, затем arm64- и universal-APK). Любой push в `main`, кроме изменений в `*.md`, = новый релиз `build-N` (N = run_number = versionCode).
- Подпись: `android/app/release.p12.enc` расшифровывается секретом репозитория `KEYSTORE_PASS`. Ключ и пароль **не трогать и не перевыпускать**: с другим ключом обновление поверх установленной версии не встанет. `.github/` меняй только по прямой просьбе.
- Локально: `flutter analyze` (0 issues) и `flutter test` (39/39). Тесты запускай с `NO_PROXY=127.0.0.1,localhost`.
- Совместимость плагинов: в Flutter 3.38.5 используется AGP 8.11. Плагины, у которых в `build.gradle.kts` есть `kotlin {}` без kotlin-плагина (рассчитаны на AGP 9), ломают сборку: так было с dynamic_color. Перед добавлением зависимости проверь это.

## Источник данных
- Старый ЭлЖур (school.lpr-reg.ru) отключён 01.09.2026 и отвечает 502. Код в `net.dart`/`parser.dart` под него — наследие версии v1.
- Сейчас: федеральный API `https://www.gosuslugi.ru/api/myschool`, запрос `POST v1/datamart`. Неофициальный, документации нет.
- Вход: WebView (`flutter_inappwebview`) открывает `gosuslugi.ru/school/feed`, пользователь входит через ЕСИА, сессия берётся из cookies `acc_t`/`u`. Пароль от Госуслуг **никогда не сохраняется**.
- `bridge.dart` перехватывает запросы веб-приложения к datamart. `myschool.dart` потом сам повторяет их («replay»).
- Реальные поля (проверено по диагностике пользователя):
  - **lessons:** `id`, `subject_name`, `room`, `theme`, `start_datetime`, `end_datetime`, ФИО учителя, `skipping_id` (пропуск). Номера урока в данных **нет**.
  - **marks:** `mark_value1`, `weight` (null = 1), `mark_date`, `period_id`, `lesson_id`, `work_type_description`, `comment`.
  - **homework:** `description`, `materials[{name,size,link,id}]`, `plan_ready_date`, `ready_lesson_id`, `subject_name`.
  - **student_classes:** `periods[{period_id, period_num, period_start_date, period_end_date, period_type_code, period_is_study}]`.
  - `interval_id` везде строка вида `"str:num"`. Интервалы пересекаются, поэтому нужен дедуп по `id`.
  - Запрос без `interval_id` → 400, и падает весь пакет запросов.
- Время уроков: школа не заполнила звонки, портал отдаёт 08:30–09:15 для всех уроков. Такое время приложение скрывает. Своё расписание звонков можно задать в Настройки → «Расписание звонков».
- Итоговые оценки (`student_pmarks`/`ymarks`): правильный `interval_id` неизвестен, поэтому работают пробные запросы. Если оценок нет, показывается прогноз с явной пометкой.

## Структура lib/
- `core/myschool.dart`: клиент API, разбор данных, дедуп, четверти, итоговые, модель номеров недель.
- `core/repo.dart`: кэш (офлайн) и сессия в secure storage.
- `core/bridge.dart`: перехват запросов WebView.
- `core/share_format.dart`: чистый текст для «Поделиться».
- `core/updater.dart`: самообновление. Берёт `releases/latest` на GitHub и сравнивает тег `build-N` с buildNumber; проверка не чаще раза в 6 ч, скачивает `dnevnik-arm64.apk`.
- `core/lock.dart`: PIN (солёный sha256) и биометрия.
- `core/diagnostics.dart`: экспорт диагностики. Содержит только структуру и количество, без значений.
- `ui/`: вкладки Лента / Расписание / Задания / Оценки / Ещё.
- Тесты: `test/portal_fixtures.dart`, `portal_schema_test.dart`, `ui_smoke_test.dart`, `share_format_test`.

## Требования владельца (обязательные)
- PIN на вход включён по умолчанию, в настройках есть переключатель, чтобы отключить.
- Вложения из ДЗ скачиваются в одно нажатие с нормальным именем файла и открываются или отправляются.
- Весь текст выделяется и копируется.
- «Поделиться» отдаёт чистый текст: без рекламы приложения, без дублей, без длинных ссылок. Можно отправлять и файлы.
- Минимум лишнего. Вкладки, стартовый экран и тема настраиваются.
- Полная работа офлайн из кэша, с плашкой «Офлайн · обновлено …», без принудительного перелогина.
- targetSdk 36, чтобы не было предупреждения «создано для более ранней версии Android».
- Отвечать по-русски, кратко. Экономить токены: одна задача — одна сессия, без долгих циклов. Бинарные файлы скачивать не через модель.

## Что не проверено / риски
- Нумерация недель (WeekIntervalModel) угадана. Если подбор не удался, оценки есть только за интервалы, которые запрашивало само веб-приложение.
- Ссылки на вложения (`materials.link`) на телефоне не проверены: возможно, нужна дополнительная авторизация.
- Неизвестно, как долго живёт сессия ЕСИА. Когда она истекает, появляется плашка «Войти», а данные остаются.
- Отметки «ДЗ выполнено» (`v2/customservices/{uuid}`) пока не используются.
- Использование неофициального API может нарушать правила портала.

## Как чинить
Попроси у владельца файл из Ещё → Диагностика → «Экспорт» (личных данных в нём нет). По нему видно ключи полей, статусы запросов и интервалы. Сначала исправление и тест на фикстуре, потом один push.
